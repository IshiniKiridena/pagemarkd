# Pagemarkd

A one-page Next.js app for tracking reading sessions and generating shareable Instagram Story cards (1080×1920).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 14 (App Router)
- Tailwind CSS
- html2canvas (client-side image export)

## Usage

1. Pick a template aesthetic
2. Log your reading session and upload a cover/mood image
3. Generate and download your story card
